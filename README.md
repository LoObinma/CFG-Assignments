# JavaScript Assignment

A two-part JavaScript project completed as part of the Code First Girls Full-Stack
Development course. The assignment covers core JavaScript concepts, DOM
manipulation and event handling through practical browser-based exercises.

## Question 1 – Daily Motivation & Habit Tracker 📓

An interactive web app that allows users to select their mood, track daily habits
and receive motivational feedback.

### Features

- Displays the current date
- Generates random motivational quotes
- Allows users to switch between visual themes
- Lets users select their current mood and receive feedback
- Provides a daily habit checklist
- Gives feedback based on mood and habit completion

### JavaScript Concepts

The app demonstrates:

- Arrays and objects
- Functions and conditional logic
- Loops
- DOM manipulation
- Event listeners
- Date handling
- Randomisation

The interface is built with HTML and CSS, with JavaScript used to provide the
interactive functionality.

## Question 2 – JavaScript Methods & DOM Events 📐

A smaller exercise demonstrating JavaScript methods and browser events.

The exercise includes:

- Array methods including `unshift()`, `shift()` and `split()`
- Object properties and methods
- Mouseover events
- Click events
- Input events
- DOM manipulation

## Technologies

- JavaScript
- HTML
- CSS

## Project Structure

`assignment-2-Javascript/` contains the Daily Motivation & Habit Tracker.

`assignment-2-javascript-Q2/` contains the JavaScript methods and DOM events
exercise.

## Running the Projects

Both projects can be run locally by opening their respective `index.html` files
in a web browser.
